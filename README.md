# نور — القرآن والأذكار (Chrome Extension)

## التثبيت / Install
1. افتح `chrome://extensions`
2. فعّل **وضع المطوّر (Developer mode)** أعلى اليمين
3. اضغط **تحميل إضافة غير مضغوطة (Load unpacked)** واختر هذا المجلد
4. ثبّت الأيقونة 📌 في شريط الأدوات

## المميزات
| القسم | المحتوى |
| --- | --- |
| 🏠 الرئيسية | الصلاة القادمة مع عدّاد، آية اليوم + تفسيرها، حديث اليوم، تابع القراءة |
| 📖 المصحف | ١١٤ سورة بالرسم العثماني، التفسير الميسر، بحث في الآيات، علامات، استماع آية بآية مع تظليل الآية الحالية |
| 🎧 القراء | جميع قراء mp3quran.net بكل الروايات، تشغيل متتابع، تكرار، تحميل MP3، مفضلة |
| 📻 الإذاعات | أكثر من ١٧٠ إذاعة قرآن مباشرة |
| 📺 القنوات | بث مباشر: قناة القرآن الكريم (مكة) وقناة السنة النبوية (المدينة) |
| 📿 الأذكار | الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، أدعية قرآنية، أسماء الله الحسنى — مع عدّاد يُحفظ يومياً |
| 📜 الحديث | البخاري، مسلم، السنن الأربعة، الموطأ، الأربعون النووية، القدسية |
| 🕌 الصلاة | حساب المواقيت بدون إنترنت، ٩ طرق حساب، تحديد الموقع، تنبيه عند الأذان وقبله |
| 🔢 السبحة | سبحة إلكترونية بأهداف ٣٣/١٠٠/١٠٠٠ وإحصائيات |
| 🔔 التذكير | آية (مع التفسير والاستماع) أو ذكر أو حديث أو منوّع — كل ساعة أو أي مدة تختارها، في نافذة منبثقة أو إشعار، مع أوقات هدوء |
| 🕌 تنبيه الصلاة | نافذة منبثقة + صوت الأذان (٣١ صوتاً) عند دخول الوقت، وتنبيه قبله بدقائق، ودعاء ما بعد الأذان |

الصوت يستمر بعد إغلاق النافذة (offscreen document). زر ⤢ يفتح الإضافة في صفحة كاملة.

## مصادر البيانات
mp3quran.net (القراء/الإذاعات/القنوات) • alquran.cloud (النص والتفسير والتلاوة آية بآية) • fawazahmed0/hadith-api (الحديث) • الأذكار من حصن المسلم.
